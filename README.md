# Tiendita - API REST con FastAPI

Proyecto desarrollado para la materia de Programación IV.

## Tecnologías

- Python
- FastAPI
- JavaScript
- HTML
- Bootstrap
- Fetch API

## Funcionalidades

- Consultar productos
- Agregar productos
- Eliminar productos

## Ejecución

### API

uvicorn main:app --reload

### Frontend

Abrir index.html mediante Live Server.

## Endpoints

GET /productos
POST /productos
DELETE /productos/{id}
